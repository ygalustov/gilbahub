## Проблема

**Что увидел владелец.** На дашборде и в `/plan` площадки Hoxton Soccer - Kate's test внесение «Primo Maxx 120» названо «Indigo Amigo (TE 120g/L)».

**Путь названия — по коду и прогону:**
1. Журнал хранит то, что ввёл человек: `spray_logs.product_name = 'Primo Maxx 120'`. Колонки кода препарата в таблице нет.
2. Сервер выводит код из названия, отдавая последнее внесение PGR: `SprayLogController::context` → `pgrProductKey` (`:231`, карта `:414–435`). Там `'primo maxx 120' => 'TE120'` и `'primo maxx' => 'TE120'` (`:418`).
3. Прогон берёт этот код из ответа сервера: `hub-tissue-v3.js`, сборка `pgr` (`:2591`, `productType: (_fromLog && _fromLog.product_key) || ""`).
4. Модуль PGR (грузится `gilba-pgr-module-v3.js`, его подключают 7 видов) берёт название по коду: `productInfo` (`:1705–1720` и копия `:1814–1829`). Там `TE120: "Indigo Amigo (TE 120g/L)"`, хотя рядом есть `PRIMO_MAXX: "Primo MAXX"`. Название уходит в `computed.pgr.product.name` строки анализа.
5. Экраны берут название из сохранённой строки: дашборд — `dashboard-init.js:769–770`, `/plan` — `plan-ui.js:414`.

**Расчёт от кода не зависит — замер.**
- Модуль переводит код в тип (`_getPT`, `:1566–1577`: `TE120` и `PRIMO_MAXX` → `TE`) и берёт порог по виду, типу и поверхности (`threshold = p(species, productType, surface)`, `:1647`).
- Поле `aiPerL` справочника не читает никто (`grep`: 0 чтений вне объявления).
- Прогон модуля на одном состоянии (Perennial Ryegrass, sports, 40 дней погоды, внесение 26.08) для `TE120` и `PRIMO_MAXX`: GDD 624 из 39 дней, порог 250, `isOverdue: true`. Результаты совпали во всём, кроме `product.name` и `product.code`.

**Сохранённые строки.** `computed.pgr.product.name` = «Indigo Amigo (TE 120g/L)» у 6 строк анализа, все Hoxton (последние 120 и 121, 30.09). Они останутся такими до следующего прогона.

## Корневая причина и класс

Торговое имя переводится в **код концентрации**, а не в запись самого препарата. Название, которое печатает расчёт, принадлежит той записи справочника, что носит этот код, то есть другому препарату той же концентрации.

Класс по 36 ключам карты (обе копии одинаковы, `diff` пуст):

| группа | ключи | что покажет экран |
|---|---|---|
| **названное** — своя запись есть, имя чужое | `primo maxx`, `primo maxx 120` → `TE120` | «Indigo Amigo (TE 120g/L)» вместо «Primo MAXX» |
| своя запись есть, имя чужое | `indigo regulate` → `PBZ200`; `trimmit`, `trimmit 2sc` → `PBZ200`; `indigo incognito` → `ETH`; `proxy` → `ETH` | «Paclobutrazol 200g/L» вместо «Indigo Regulate» и «Trimmit 2SC»; «Ethephon» вместо «Indigo Incognito» и «Proxy» |
| своя запись есть, имя то же | `primo 250ec`, `primo 250 ec` → `TE250` (есть `PRIMO250`) | «Primo 250 EC» — разницы на экране нет |
| своей записи нет | `primo maxx 1ec`, `marvel`, `marvel 175`, `indigo marvel`, `indigo marvel 175` → `TE175` | «Indigo Amigo (TE 175g/L)» |
| только действующее вещество | `trinexapac-ethyl`, `trinexapac ethyl` → `TE250` | «Primo 250 EC» — торговое имя у записи без торгового имени |

На стенде в журнале 5 внесений, и из класса на экран выходит только названное:
- «Primo Maxx 120» — 2 записи: Hoxton Soccer - Kate's test и площадка владельца Kate's test NZ (её не трогаем, у её записи зона `other`);
- «Primo 250EC» → «Primo 250 EC» — верно;
- «Amigo 175» → «Indigo Amigo (TE 175g/L)» — тот же препарат;
- фунгицид.

**Укладывается ли класс в нынешнее устройство.** Да. Справочник — единственный источник названия, а карта — единственное место, где торговое имя превращается в ссылку на запись. Приём для названного: имя ведёт на запись самого препарата. Расчёт не меняется, потому что тип у обеих записей `TE`.

## Подводные камни

1. **Не менять название в справочнике.** Переименовать `TE120` в «Primo MAXX» было бы неверно: запись `TE120` значит Indigo Amigo 120, и у Amigo 120 (`'amigo 120'`, `'indigo amigo 120'` → `TE120`) название стало бы чужим.
2. **Не переводить карту на «запись по концентрации» и не трогать остальные группы класса** — это предложение ниже, оно требует решения.
3. **Сохранённые строки не переписываются.** Шесть строк Hoxton показывают старое название до прогона. Переписывать строки анализа задним числом — не эта работа, и данные стенда мы не правим.
4. **Две копии карты.** Если поменять только серверную, браузерная копия расходится в двух ключах. Если только браузерную — на экране ничего не изменится: прогон берёт код с сервера.

## Предложение, требует решения — в работу не входит

**Остальной класс карты.** 5 ключей с чужим именем при своей записи:
