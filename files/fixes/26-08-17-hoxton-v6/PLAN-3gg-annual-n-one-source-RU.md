## Устройство

**Одна функция нормы — `annualNBaseOf(siteConfig)` — в `nutrition-program-inputs.js`, рядом с правилом, которое там уже есть.** Возвращает `{ value, source }`:
1. `nutritionCalendarProgram.meta.annualNBase > 0` → `source: 'programme'`;
2. иначе у программ до GH-383 — `adjustments.target_n / traffic_modifier` (как сегодня в резолвере и в восстановлении календаря) → `'programme'`. На стенде таких 0 из 11: у всех есть `meta.annualNBase`;
3. иначе `turf.nProgram > 0` → `'settings'`;
4. иначе `{ value: null, source: null }`.

Полей страницы, глобалов страницы, вида травы функция не знает.

**Устаревшая программа — моё решение: её норма берётся.** Годовая норма — число, которое человек ввёл сам. `plan-calc-trace.js` так её и печатает: «Annual N target (as entered)». Устаревание (другие координаты, дрейф входов) относится к помесячной раскладке, выведенной из этой нормы, а не к самой норме. Поэтому ворота GH-371/GH-377 остаются у восстановления раскладки и к норме не применяются. На стенде устаревших по координатам 0 из 11 (`nutritionProgramCoords` = `location` у всех); дрейф входов по базе не виден. Если ворота нужны и для нормы, это вопрос владельцу. Я его не задаю: по её словам программа — источник, про устаревание она не оговаривала.

**Перечень входов — первым.** У `turf.nProgram` сегодня `storedIn: ["config"]` без пути программы. Объявляются оба места хранения, в порядке функции: `nutritionCalendarProgram.meta.annualNBase`, затем `turf.nProgram`. Синтаксис — по образцу существующих `storedAs`. - **`/plan`, «Seasonal N Plan»** — у 9 площадок из 11 норма программы вместо Settings: `Federal Golf`, `Burns`, `New test`, `test4 - USA`, `Test1 - Sports` → 120; `Test6 - UK`, `Westview` → 200; `delivery`, `warm season` → 250. Помесячная раскладка раздела — от этой нормы.
- **Анализ** — у `Burns`, `Test1 - Sports`, `test4 - USA` после Re-run азот, твёрдость и то, что от них зависит, по норме программы. У остальных — как сейчас, но без гонки.
- **Экспорт** — разделы питания как сейчас. Проверка взаимодействий Малдера впервые видит норму азота и может добавить строки о взаимодействиях с азотом. Сколько — **не мерено**.
