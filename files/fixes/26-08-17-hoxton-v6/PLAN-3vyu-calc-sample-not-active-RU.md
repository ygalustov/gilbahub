## Устройство: одна функция «проба расчёта», один владелец правила

- **Правило «какую пробу берёт расчёт» уже принадлежит серверу.** «Последняя по `COALESCE(lab_date, sample_date) DESC, id DESC`» — это `askServerForSample` в `dashboard-ui.js`, её комментарий: «The choice is the SERVER'S». Кадр прогона получает ответ адресом, `&soil=`, `&tissue=`.
- **Новая функция `SM.calculationSample(kind)`** в `sample-manager.js`, который грузится везде, где есть пробы. Одна на все места:
  - **в кадре прогона** (адрес несёт `rerun`) — названное адресом, тем же разбором, что сегодня `gaip_namedSample`. Разбор переезжает сюда, выбирающая функция кадра зовёт `SM.calculationSample`;
  - **в кадре без параметра** (№ 1) и **на страницах** (`/plan`, отчёты) — ответ сервера по тому же правилу. Та же `askServerForSample`, один запрос на вид за загрузку страницы, ответ хранится до перезагрузки. Проба находится в хранилище по `serverId` — план `PLAN-item4-sample-identity-RU.md`;
  - `none` — пробы нет, расчёт делает то же, что сегодня без пробы;
  - `unknown` — исход пункта 3вэ, не активная;
  - **активную не возвращает никогда.**
- **Годится ли `gaip_passSampleIds` и отпечаток принятого прохода.** Как **запись** — да: отпечаток строится тем же выбором и в кадре останется согласован. Как **источник** для страниц — нет: он живёт только в кадре прогона, а `/plan` и отчёты его не видят. Источник для всех — одна функция выше. Отпечаток по-прежнему пишет то, что она ответила.
- **Места № 2–5 и № 7** зовут `SM.calculationSample(kind)` вместо `SM.getActiveSample(kind)`. № 6 удаляет запасной путь. № 23 читает дату и глубину из пробы расчёта.

## Как проверяется «на странице ничего не поломали» — её прямое условие

1. **Случай расхождения, на стенде без живого окна.** В хранилище две пробы, активна A, сервер называет B.
   - **Расчёт — против внешнего:** программа питания, соотношения Mulders и входы документа берут значения B. Сверка с собственными показаниями пробы B в хранилище, по каждому показателю.
   - **Страница — не тронута:** переключатель (№ 8–11) подписан A, список (№ 12–13) — A, график тренда (№ 16) прикреплён к зоне A, после импорта (№ 15) открыта новая проба.
   - Мутации ревьюера, например: вернуть `getActiveSample` в № 3 — красный на расчёте; заменить № 8 на `calculationSample` — красный на странице.
2. **Живое сравнение — главное для её условия.** По 3вч у 4 площадок с несколькими пробами почвенная активная сегодня совпадает с названной — **0 расхождений из 4**. Значит, после правки экран не должен измениться ни у одной площадки.
   - В окне снимаются числа `/plan` (программа, продукты) и экспорт `/plan` по **13 из 13** площадок с прогоном — до правки и после.
   - Признак: **различий 0 из 13**. Любое различие печатается поимённо и разбирается: оно допустимо, только если у этой площадки активная и названная разошлись. Это видно по ответу сервера и номеру активной, которые тест печатает рядом.
   - Совпадение активной и названной по **ткани** сегодня не мерено. Тест печатает его первым шагом.
